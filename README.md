# Civil-3D-and-CAD-search-engine

Civil 3D and AutoCAD command + shortcut search interface.

## Run locally

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

The interface lets users type natural-language tasks (for example, "how do I create a corridor?") and returns matching commands/shortcuts.
